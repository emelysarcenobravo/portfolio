# Emely Sarceno Bravo — Portfolio

The portfolio of a computer science student (minor in marketing) at San Francisco State University who builds digital experiences where technology, people and data meet.

**Visit the live site: [portfolio-emelysarcenobravo.vercel.app](https://portfolio-emelysarcenobravo.vercel.app/)**

## What you'll learn from this portfolio

**How I think, not just what I built.** Each project is told as a short story: the problem, the people it was for, the design and build decisions, and what changed as a result. You can see the reasoning behind the work, not only the finished product.

**Range across four kinds of work.** Software engineering, AI and machine learning, UX and design, and marketing and data. Most of my projects use more than one, and the site lets you filter by whichever matters most to you.

**Results backed by numbers.** Where a project had a measurable outcome, it's shown up front: a phishing detector that reached 99.28% accuracy, a 2,600% increase in online donations for a nonprofit, and a recruiting campaign that brought in 100+ trainees and 15+ mentors.

**Experience working on teams.** From leading a six-person engineering team to pitching a concept to a client, the portfolio shows how I coordinate, communicate and hand off work that keeps running after I leave.

**A people-first approach.** I start with the real problem and the person it affects, and I reach for the simplest solution that works. In my AI research, that meant a straightforward model outperforming a far more complex one.

**Technical depth from the ground up.** The work ranges from full-stack web apps and REST APIs down to a Linux kernel module and object-oriented C++, alongside data analysis and machine learning.

- **TypeScript**
- **Tailwind CSS 4**
