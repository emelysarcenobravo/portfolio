# Emely Sarceno Bravo — Portfolio

Personal portfolio website showcasing my work across **software engineering, AI, UX/design, and marketing**.

## Live Website

**[View my portfolio](https://portfolio-emelysarcenobravo.vercel.app/)**

## About

I’m interested in the intersection of technology, creativity, and people. This portfolio highlights selected projects, skills, and experiences while showing both the technical work behind my projects and the people they are designed to serve.

## Built With

* Next.js
* React
* TypeScript
* Tailwind CSS
* Vercel

## Features

* **Multiple project lenses** — Explore my projects from four different perspectives:

  * **Build** — software engineering, development, and technical implementation
  * **AI** — artificial intelligence, data, and intelligent systems
  * **Design** — UX, UI, user research, and design decisions
  * **Marketing** — strategy, audience, communication, and measurable outcomes
* Responsive design
* Project and case study showcase
* Skills and experience sections
* About and contact sections
* Light and dark mode
* Accessible navigation
* Responsive layouts for desktop and mobile
